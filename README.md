# خانه‌ورز — برنامه ورزش در خانه (PWA)

یک اپلیکیشن وب پیشرونده (PWA) برای پیگیری تمرین‌های خانگی. کاملاً آفلاین کار می‌کند و همه‌ی اطلاعات (قد، وزن، ست‌های ورزشی، اندازه‌گیری بدن) داخل خود گوشی/مرورگر ذخیره می‌شود.

## فایل‌ها
- `index.html` — صفحه اصلی
- `style.css` — استایل
- `app.js` — تمام منطق برنامه (تقویم شمسی، ذخیره‌سازی، تب‌ها، ثانیه‌شمار)
- `manifest.json` — تنظیمات نصب روی گوشی
- `sw.js` — سرویس‌ورکر برای کار آفلاین
- `icon-192.png` / `icon-512.png` — آیکون برنامه

همه‌ی فایل‌ها کنار هم و بدون پوشه هستن؛ می‌تونی مستقیم داخل ریشه‌ی یک ریپوی گیت‌هاب آپلودشون کنی.

## آپلود در گیت‌هاب و فعال‌سازی GitHub Pages
1. یک ریپوی جدید بساز (مثلاً `khane-varz`).
2. همین فایل‌ها رو (بدون پوشه، مستقیم در ریشه ریپو) آپلود کن.
3. برو به Settings → Pages → از قسمت Branch گزینه `main` و پوشه `/root` رو انتخاب کن و Save بزن.
4. بعد از چند دقیقه آدرسی مثل `https://username.github.io/khane-varz/` فعال میشه.
5. اون آدرس رو داخل گوشی با کروم یا سافاری باز کن و از منو گزینه «افزودن به صفحه اصلی / نصب» رو بزن تا مثل یک اپ روی گوشی نصب بشه.

## نکته مهم درباره‌ی ذخیره‌سازی
مرورگرهای موبایل (اندروید و آیفون) اجازه نمی‌دن یک برنامه‌ی وب مسیر دلخواه روی حافظه گوشی رو برای ذخیره‌سازی انتخاب کنه (این قابلیت فقط در برخی مرورگرهای دسکتاپ هست). به همین خاطر برنامه از حافظه‌ی داخلی مرورگر (IndexedDB) استفاده می‌کنه که:
- خودکار و برای همیشه ذخیره می‌مونه،
- با رفرش یا بستن برنامه پاک نمی‌شه،
- فقط بار اول یک پیام خوش‌آمد نشون داده میشه (برای درخواست «ذخیره‌سازی پایدار» از مرورگر) و بعد از اون دیگه هیچ سوالی پرسیده نمی‌شه.

فقط کافیه هر بار از همون آدرس (یا همون آیکون نصب‌شده روی گوشی) وارد بشی تا به همون اطلاعات قبلی دسترسی داشته باشی. اگر کش/داده‌های سایت رو از تنظیمات مرورگر پاک کنی، طبیعتاً اطلاعات هم پاک میشه (این محدودیت همه‌ی برنامه‌های وب آفلاینه).

## امکانات
- پروفایل: قد و وزن
- تب هر روز هفته (شنبه تا جمعه): افزودن/ویرایش/حذف ست ورزشی (وزنه‌ای یا زمانی)
- ثانیه‌شمار برای ست‌های زمانی + آلارم صوتی و لرزش گوشی وقتی زمان تمام میشه
- تب «جدول»: همه‌ی ست‌های ثبت‌شده، با نمایش ۵ تای اول و دکمه «نمایش همه»
- تب «نتیجه‌گیری»: ثبت اندازه‌گیری بدن (دور بازو/شکم/پا/سینه) + مقایسه‌ی پیشرفت هفتگی هر حرکت بر اساس تقویم شمسی
